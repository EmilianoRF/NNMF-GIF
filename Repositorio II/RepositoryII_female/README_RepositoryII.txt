README_RepositoryII

Repository II consists of two zip folders:

RepositoryII_male.zip
RepositoryII_female.zip


RepositoryII_male contains 48 wav files of utterances synthesized using the male configuration. Each file is named

Male_[vowel]_[fundamental frequency]_[degree of vocal fold adduction].wav

- vowel: a, i, u, or ae
- fundamental frequency: 82, 110, 156 or 220 Hz
- degree of adduction: small = 0.03 cm, medium = 0.06 cm, or large = 0.09 cm
- full lisf of vowel-fo-adduction combinations is given below*

Each file has three channels
- channel 1: speech pressure signal
- channel 2: glottal flow (volume velocity)
- channel 3: glottal area


RepositoryII_female contains 48 .wav files of utterances synthesized using the female configuration. Each file is named

Female_[vowel]_[fundamental frequency]_[degree of vocal fold adduction].wav

- vowel: a, i, u, or ae
- fundamental frequency: 175, 194, 220 or 294 Hz
- degree of adduction: small = 0.05 cm, medium = 0.07 cm, or large = 0.09 cm
- full lisf of vowel-fo-adduction combinations is given below**

Each file has three channels
- channel 1: speech pressure signal
- channel 2: glottal flow (volume velocity)
- channel 3: glottal area
